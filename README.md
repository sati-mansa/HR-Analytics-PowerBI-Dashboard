# HR Analytics Power BI Dashboard

## Project Overview

This project is an interactive HR Analytics Dashboard created using Microsoft Power BI. The dashboard helps analyze employee attrition and understand workforce trends through interactive visuals and filters.

## Key KPIs

- Total Employees
- Employees Left
- Attrition Rate
- Average Salary
- Average Age

## Dashboard Analysis

The dashboard provides insights into:

- Employee Attrition by Department
- Employee Attrition by Job Role
- Employee Attrition by Gender
- Employee Attrition by Age Group
- Overtime vs Attrition
- Job Satisfaction
- Work-Life Balance
- Years at Company
- Employee-level Attrition Details

## Tools & Skills Used

- Microsoft Power BI
- DAX
- Data Cleaning
- Data Visualization
- Data Analysis
- Dashboard Design

## Dashboard Pages

### 1. HR Overview
Provides a high-level overview of employee count, attrition, salary, age, department, job role, gender, and overtime.

### 2. Attrition Details
Provides detailed analysis of job satisfaction, work-life balance, years at company, and employee-level attrition information.

## Project Objective

The objective of this project is to identify employee attrition patterns and provide meaningful HR insights that can support better workforce management and decision-making.
